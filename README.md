# Auto Mouse Clicker

Auto Mouse Clicker is a lightweight, portable Windows utility for automated left and right mouse clicking. It provides independent click-speed control, quick CPS presets, global start and stop hotkeys, live click counters and a safety-focused arming workflow. The application operates locally and does not require an internet connection.

## Features

- Left and right mouse click automation
- Independent CPS control
- CPS range from 1 to 10,000
- Quick presets: 50, 100, 150, 500, 1000 and Max
- Arm, wait for a physical click, then start
- Global F1 Arm hotkey
- Global Esc and F2 stop hotkeys
- Physical opposite-button safety interlock
- Live Total, Left and Right click counters
- Completed-session results remain visible until the next session
- Portable Windows x64 application
- No installation required
- No administrator privileges required
- Local settings and diagnostic log files

## Quick Start

1. Download the portable EXE.
2. Enable Left Click, Right Click, or both.
3. Select the required CPS.
4. Click **ARM REPEATER** or press **F1**.
5. Physically click an enabled mouse button to begin.
6. Press **Esc**, **F2** or **STOP** to stop.

## Keyboard Shortcuts

- **F1:** Arm
- **Esc:** Stop immediately
- **F2:** Stop immediately

## Privacy & Connectivity

Auto Mouse Clicker operates locally and does not require an internet connection. It does not use user accounts, cloud services, telemetry or automatic update checks. Settings and diagnostic logs are stored locally on the computer.
